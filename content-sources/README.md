# Content Sources

Drop source files here for future CMS import pipelines.

## Intended use

- **PDFs** — annual reports, impact reports, publications
- **Spreadsheets** — metrics, partner lists, event schedules
- **Legacy exports** — HTML dumps, redirect maps, media inventories
- **Draft copy** — page text pending editor review

## Workflow

1. Place files in this folder (do not commit sensitive personal data).
2. Note the source and date in the filename, e.g. `2024-annual-report.pdf`.
3. Editors import or transcribe verified content through the admin CMS.
4. Mark verification status and safeguarding requirements before publishing.

## Not imported automatically

Nothing in this directory is read by the live application. Imports are manual or scripted in later phases.
