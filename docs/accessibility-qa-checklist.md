# ASNEN Accessibility QA Checklist (WCAG 2.2 AA)

Use with the site-wide **Accessibility preferences** panel (bottom-left button, or `Alt+0`). Preferences persist in the browser and apply to public pages, login, and admin.

## Tools to verify

- [ ] Keyboard-only navigation (Tab / Shift+Tab / Enter / Escape)
- [ ] Screen reader spot-check (NVDA / VoiceOver) on home, contact form, event registration
- [ ] Zoom to 200% and 400% — no loss of content or horizontal overflow for primary tasks
- [ ] Windows High Contrast / forced-colors (where available)
- [ ] `prefers-reduced-motion` and in-panel “Reduce motion”
- [ ] Colour contrast of text/UI ≥ 4.5:1 (or 3:1 for large text)

## Site-wide features

- [ ] Skip links: main, navigation, footer, accessibility panel
- [ ] Accessibility FAB visible and operable
- [ ] Text size / spacing modes
- [ ] High contrast and dark modes
- [ ] Readable font (Atkinson Hyperlegible)
- [ ] Underline links, strong focus, heading highlight
- [ ] Large targets, large cursor
- [ ] Easy-read summaries on Home and Accessibility statement
- [ ] Form error summary announced (`role="alert"`)

## Content & media

- [ ] Meaningful images have useful alt text; decorative images marked appropriately
- [ ] Videos/webinars offer captions or transcripts when published
- [ ] No information by colour alone
- [ ] Safeguarding-gated stories cannot publish without approval

## Feedback

Barriers can be reported via the contact form or `info@asnenafrica.org`.
